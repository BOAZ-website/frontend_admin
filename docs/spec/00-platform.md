# 플랫폼 기반 기능명세서

| 항목 | 내용 |
| --- | --- |
| 범위 | 모든 도메인이 공유하는 공통 바닥 — 배포 · 라우팅 · 인증 · API 클라이언트 · 서버 상태 · 공용 컴포넌트 · 테스트 · 모니터링 |
| 근거 자료 | 기존 WBS `T0.0` ~ `T0.11`(현재 `PLT-*` 키로 개칭), 5개 도메인 기능명세서에서 반복 등장한 공통 요구 |
| 상태 | v1.0 — 기존 WBS 티켓을 명세 형식으로 정리하고 도메인 명세서의 공통 요구를 귀속 |

> **이 문서는 당위 문서이며, 도메인 기능명세서 5종([`03`](03-recruiting.md) ~ [`07`](07-content.md))의 공통 바닥이다.** 개발 순서와 규모는 [`01-wbs.md`](../01-wbs.md)의 Epic 0을 본다.
> 다른 명세서가 화면 ID를 쓰는 것과 달리 이 문서는 사용자 화면이 아니라 개발 기반이라 **`PLT-*` 티켓 키를 쓴다.**

---

## 1. 문서 목적

- 도메인 명세서(리크루팅 · 서류 평가 · 출결 · 시스템·계정 · 콘텐츠) 5종에서 **반복해 등장하는 공통 요구**를 한곳에 모아 정의한다.
- 각 도메인 화면이 무엇을 전제로 만들어지는지(라우터 · 인증 컨텍스트 · API 클라이언트 · 공용 컴포넌트) 명시한다.
- Epic 0 종료 기준(M0)을 정의한다.

> Epic 0은 사용자 화면이 아니라 **개발 기반**이다. 화면 ID 대신 `PLT-*` 티켓 키를 쓴다.

---

## 2. 구성

| 영역 | 티켓 | 담당 | 도메인 의존 |
| --- | --- | --- | --- |
| 배포 · 라우팅 · 상태 해체 | `PLT-DEPLOY` 프론트 CD 파이프라인 · `PLT-ROUTER` 라우터 도입 · `PLT-STATE` 출결 공유 상태 해체 | FE (`PLT-DEPLOY`는 + 인프라) | 전체 · 출결(`PLT-STATE`) |
| 인증 · 통신 | `PLT-SESSION` 로그인 · 토큰 · 인증 컨텍스트 · `PLT-CLIENT` API 클라이언트 · `PLT-QUERY` 서버 상태 관리 | FE + BE (`PLT-QUERY`는 FE) | 전체 (`PLT-SESSION`은 SYS-GATE 전제) |
| 공용 UI · 메시지 | `PLT-STATUS-UI` 로딩·에러·빈 상태 · `PLT-FORM` 폼·검증·업로드 · `PLT-CONFIRM` 확인 모달 · `PLT-ERRMSG` 에러 코드 → 한글 매핑 | FE (`PLT-ERRMSG`는 + BE) | 전체 |
| 검증 | `PLT-PILOT` 파일럿 1화면(FAQ) · `PLT-TEST` 테스트 도구 · `PLT-MONITOR` 오류 수집 | FE | 콘텐츠(`PLT-PILOT`) |

## 3. 티켓별 명세

### PLT-DEPLOY 프론트 CD 파이프라인

| 항목 | 내용 |
| --- | --- |
| 목적 | 빌드 결과를 운영 환경에 자동 배포 |
| 동작 | 빌드 → `boaz-prod-frontend-admin` S3 동기화 → CloudFront invalidation |
| 선행 | OIDC Role에 CloudFront 권한 추가 |
| 완료 기준 | main 병합 시 자동 배포, 배포 후 무효화 확인 |

### PLT-ROUTER 라우터 도입 + 무상태 화면 이관

| 항목 | 내용 |
| --- | --- |
| 목적 | 탭 상태 기반 화면 전환을 URL 경로 기반으로 전환 |
| 동작 | 22경로 ↔ `ActivePage` 31키 대응 · props 없는 8개 화면 이관 · 허브 대표키 4개 index 리다이렉트 · `startsWith` 접두사 판정 정리 |
| 예약 | 경로 가드 자리 확보 (SYS-GATE에서 사용) |
| 완료 기준 | 새로고침 시 현재 화면 복원 |

### PLT-STATE 출결 공유 상태 해체

| 항목 | 내용 |
| --- | --- |
| 목적 | `App.tsx`에 몰린 출결 전역 상태를 화면 소유로 분산 |
| 동작 | 상태 인벤토리(서버 / 클라이언트 / URL / 폼) → 공유 상태 5개(`attendance` `studyTeams` `membersMap` `hosts` `exceptions`) 소유권 이전 → 죽은 이벤트 코드 · `activeScoreRule` prop 정리 |
| 원칙 | 전역 클라이언트 상태는 **세션 · UI 토글만**. 도메인 목업 상수는 화면 하위로 |
| 비고 | 출결 명세 v2.0으로 화면 구성이 바뀌므로, 이관 대상 화면은 v2.0 IA 기준으로 재확인 |

### PLT-SESSION 로그인 · 토큰 · 인증 컨텍스트

| 항목 | 내용 |
| --- | --- |
| 목적 | 인증 상태를 전 화면이 공유 |
| 동작 | 로그인 화면 · 토큰 발급 연동 · 저장 · 갱신 · 만료 · 로그아웃 |
| 컨텍스트 | `role` · `teamName` · `track` + **서버가 준 permission 목록** (`GET /admin/accounts/me`) |
| 도메인 의존 | SYS-GATE의 판정 근거. 시스템·계정 명세 3장 권한 체계 참조 |

### PLT-CLIENT API 클라이언트

| 항목 | 내용 |
| --- | --- |
| 목적 | 도메인별 요청이 같은 규약을 따르게 |
| 동작 | 요청 래퍼(베이스 URL · 인터셉터 · 타임아웃) · 토큰 첨부 · 401 처리 결선 · 응답 스키마 검증 · 도메인별 요청 함수 스캐폴드 |
| 완료 기준 | 401 시 갱신 또는 로그아웃 경로 동작, 스키마 불일치 시 오류 표시 |

### PLT-QUERY 서버 상태 관리

| 항목 | 내용 |
| --- | --- |
| 목적 | 조회 데이터의 캐싱과 변경 후 갱신을 표준화 |
| 동작 | 캐싱 · 재검증 · 변경 후 무효화 · 중복 요청 제거 · 재시도 |
| 도메인 의존 | 출결 명세 3.4절 **SOT 파생 뷰 원칙**(명단 수정이 즉시 모든 파생 화면에 반영)은 이 계층의 무효화로 구현 |

### PLT-STATUS-UI 로딩 · 에러 · 빈 상태 공용 컴포넌트

| 항목 | 내용 |
| --- | --- |
| 목적 | 세 상태의 표현을 전 화면에서 통일 |
| 동작 | 로딩 · 에러 · 빈 상태 3종 |
| 도메인 귀속 | 출결 ADV-05 미진행 주차 · STD-01 미제출 스터디 · LDR-04 미제출 상태 · 서류 평가 `DRAFT` 판정 공란 |

### PLT-ERRMSG 에러 코드 → 한글 메시지 매핑

| 항목 | 내용 |
| --- | --- |
| 목적 | 사용자에게 영문 에러 코드가 노출되지 않게 |
| 동작 | 기존 ErrorCode 매핑 + 신규 20종(`NOT_GROUP_HOST` `SESSION_ALREADY_SUBMITTED` `DUPLICATE_SESSION_WEEK` `INVALID_MEMBER_CSV` 등) · `alert` 영문 노출 정리 |
| 도메인 귀속 | 시스템·계정 락아웃 거부 사유 · 출결 주차 경과 거부 · 서류 평가 `DRAFT` 평가 차단 |

### PLT-CONFIRM 파괴적 액션 확인 모달 공용

| 항목 | 내용 |
| --- | --- |
| 목적 | 되돌릴 수 없는 처리 전 확인 절차 통일, 브라우저 `confirm()` 전수 제거 |
| 동작 | 대상 id · 제목 표시 + 2단 확인. 삭제 범위(예: 참가자 N명 동시 삭제) · 비가역 문구 · 선행 조건 상태 표시 슬롯 |
| 강화 옵션 | 대상 이름 직접 입력 후 활성화 (행사 삭제 1명 이상, 지원서 전체 삭제) |
| 도메인 귀속 | 출결 EVT-07 행사 삭제 · ROS-04 기록 있는 인원 불참 전환 · 서류 평가 PROM-03 승격 · DEL-03 지원서 전체 삭제 · 시스템·계정 ACC-06 계정 삭제 · 콘텐츠 삭제 4종 · 리크루팅 공고·문항 삭제 |

## 5. 도메인 명세서 → Epic 0 귀속 요약

| 도메인 요구 | 귀속 티켓 |

| 삭제 · 승격 · 확정 전 확인 절차 (5개 명세서 공통) | PLT-CONFIRM |

| 한글 오류 메시지 | PLT-ERRMSG |
