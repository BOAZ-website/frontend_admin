# EPIC별 개발 기능 (기능명세서 기준)

> 기준 문서: [`spec/`](spec/README.md)의 기능명세서 6종 — 플랫폼 기반 · 리크루팅 공고 · 서류 평가 · 출결 관리 · 시스템·계정 · 콘텐츠 관리
> 화면 ID와 기능 ID의 정의는 명세서에 있고, 이 문서는 그것을 순서·규모·담당으로 옮긴다.

---

- 티켓 키 = 명세서 **화면**
- 하위 항목 = 명세서 **기능 ID**
    - 공통 기반은 플랫폼 기반 명세서의 `PLT-*` 키를 쓴다.
- 규모 `하루이틀` · `한 주` · `2~3주` · `한 달 이상`. 담당 `FE` / `BE` / `인프라` / `디자인`.
    - ⏳ = 명세서 Open Issue 회신 대기. 해당 항목은 회신 전 착수 불가.
    - API 확인 항목은 명세서별 접두사로 구분한다 — `ATT-` 출결 · `REC-` 리크루팅 · `EVL-` 서류 평가 · `SYS-` 시스템·계정 · `CNT-` 콘텐츠.
    - 선행 칸에는 ID와 함께 **그 선행이 무엇을 확정하는 작업인지**를 기록한다.

# Epic 1 · 리크루팅 관리

> 리크루팅 기능명세서

**공고와 문항을 실데이터로 등록.** 모집 공고 / 지원서 문항 / 지원자 / 사전 알림 API가 이미 구현되어 있어 연동이 중심이다.
명세서 상태: PoC — 디자인 확정 후 화면 재구현.

# Epic 2 · 서류 평가

> 서류 평가 기능명세서

**평가자가 제출 완료 지원서를 심사하고, 운영진이 최종 합불과 정회원 승격을 처리한다.** 지원자 · 평가 · 승격 API가 이미 구현되어 있다.
명세서 상태: PoC — 특히 **평가 입력 화면은 PoC에 없어 신규 설계**.

# Epic 3 · 출결 관리

> 출결 관리 기능명세서

**운영지원팀이 명단·출결·점수를 관리하고, 스터디장·ADV 팀장이 인증을 제출한다.** 이 프로젝트에서 유일하게 백엔드가 신규다.
명세서 상태: **v2.0** — 운영지원팀 요구사항 기준 전면 개정. 회신 대기 항목 0건.

> v1.x 대비: `ATT-ROSTER` · `ATT-VIEW` · `ATT-GROUP` 신설
> - `SET-HOST` → `ATT-GROUP` 흡수
> - `ATT-MAN` 삭제(요구사항 범위 밖)
> - `ATT-SUM` 재정의(중간은 화면 조회, export는 최종 3종)

**확정 완료 — 착수를 막는 결정이 없다.** [`spec/05-attendance.md`](spec/05-attendance.md) §9 기준이다.

| # | 항목 | 결론 |
| --- | --- | --- |
| ATT-A-1 | 병행 인원 | BASE 명단 자동 포함, "병행" 표시, 감점 동일. Term 판정 점수는 시스템 밖 |
| ATT-A-2 | 비대면 횟수 | 팀별 카운트 · 팀 헤더 표시 · 초과 경고 없음 · 결석 전환 시 대면 인정 · 예외분은 기수 전체 기준 |
| ATT-A-3 | 행사 유형 | 3유형 정의 완료. 대상은 `(필참 ∪ 참여) ∩ 기수·부문` |
| ATT-A-4 | 인증 방식 | **인증 사진 제출 확정.** 컨펌 시점에 기록 반영 |
| ATT-A-5 | 부원 불러오기 | 행사별 명단 업로드 불필요. import는 명단 1종 |

유일한 미결은 `ATT-B-1`(점수 규칙 Term 단위 보관 + 행사 오버라이드)이며 백엔드 검토 중이다. `SET-RULE`의 `RULE-04` · `RULE-05`가 여기에 걸린다.

| 3.5 | 인가 없던 6 컨트롤러 31 EP 최초 닫기 (콘텐츠 4도메인 18 EP 한 묶음) | 예 |
| 4 | 서비스 role 비교 11곳 → `ScopeGuard`, `findEvaluatorPool` 인자 제거 | 예 |
| 5 | 권한 커스텀 API · `Permission.values()` · `/me` 확장 · `AdminMeResponse` 리더십 기준 | 예 |

- 0·1단계 한 배포. prod 수동 SQL: CREATE TABLE 2건 → 배포 → 백필.
- 출결 도메인 착수 시 `admin_group_leader` FK `ALTER` + 출결 permission 22개 부착 (ATT-CORE 체크리스트).
- 트랩: ERROR 디스패치 403 · local/dev Swagger · `/actuator/health` · CORS 프리플라이트.
