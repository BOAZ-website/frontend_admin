# Attendance System Design

This is a code bundle for Attendance System Design. The original project is available at https://www.figma.com/design/Nc3PT4m7sr0Tq8NjkuJdbD/Attendance-System-Design.

## Running the code

Use Node.js 24.15.0 (`.nvmrc`) and run `npm ci` to install the dependencies.

Run `npm run dev` to start the development server.

See [CONTRIBUTING.md](CONTRIBUTING.md) for branch conventions, pull requests, local checks, CI, and review setup.
